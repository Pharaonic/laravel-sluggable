# Changelog

All notable changes to this project will be documented in this file.

## 9.0.0 - 2026-10-07

### Compatibility

- Added support for Laravel 9.x (`illuminate/*` ^9.33) on PHP 8.0, 8.1 and 8.2.
- Requires `pharaonic/php-slugify` 8.0.4+ (PHP 8.0), 8.1.2+ (PHP 8.1) or 8.2.1+ (PHP 8.2).
- Requires Laravel 9.33 or newer, the first 9.x release that requires a `nesbot/carbon` compatible with PHP 8.2.
- Same features and behavior as 8.0.0.

## 8.0.0 - 2026-10-07

### Compatibility

- Added support for Laravel 8.x (`illuminate/*` ^8.75) on PHP 8.0 and 8.1.
- Requires `pharaonic/php-slugify` 8.0.4+ (PHP 8.0) or 8.1.2+ (PHP 8.1), which allow the `voku/portable-ascii` 1.x that Laravel 8 requires.
- Same features and behavior as 7.0.0.

## 7.0.0 - 2026-10-07

### Compatibility

- Added support for Laravel 7.x (`illuminate/*` ^7.30) on PHP 8.0.
- Requires `pharaonic/php-slugify` `~8.0.4`, the first 8.0.x release compatible with the `voku/portable-ascii` 1.x that Laravel 7 requires.
- Same features and behavior as 6.0.0.

## 6.0.0 - 2026-10-07

### Added

- `sluggable()` method for any number of slug columns per model, one source each.
- Callable sources (`fn ($model) => ...`) for relations, accessors and computed values.
- Per-slug options: `source`, `separator`, `unique`, `on_update`, `include_trashed`, `max_length`.
- `include_trashed` and `max_length` configuration options.
- `$table->sluggable($column = 'slug')` accepts the target column name.

### Changed

- `sluggable()` takes precedence over the `$sluggable` property; the two are never merged.
- Unique slugs are resolved with a single query per column and continue from the highest suffix (`hello`, `hello-2`, `hello-3`, ...). LIKE wildcards in slugs are escaped.
- Unique suffixes respect `max_length`.
- `on_update` now defaults to `false`: an existing slug is kept when its source changes.
- A slug is generated on create only when its column is empty; a manually assigned slug is never overwritten.
- `$table->sluggable()` creates a nullable, unique string column.
- Slugs are generated by `pharaonic/php-slugify` 8.0.
- Slug columns are added to `$fillable` only when the model uses a fillable list.
- A model using the trait without any slug configuration no longer throws.

### Removed

- `AboutCommand` registration (not available in Laravel 6).
- PHP CS Fixer in favor of Laravel Pint.

### Compatibility

- Added support for Laravel 6.x on PHP 8.0.
- Requires `pharaonic/php-slugify` `~8.0.3`.
